## The joke

> I expensed a coffee as 'client relationship development' and finance approved it, so my caffeine addiction is now officially a business strategy.

One line, 145 characters — inside the 200-character limit.

## How it works

`main.py` prints the joke and writes the exact same text to `/output/entry.txt`
(or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set), where the bounty harness reads it.
No dependencies, no network, deterministic output.

```sh
python3 main.py
```

## Why this line

The field is saturated with meetings, reply-all emails, printers and
"HR says we're a family" — so this entry mines open ground instead: the
expense report. A coffee filed as "client relationship development",
approved by finance, turns a caffeine habit into official business
strategy. One sentence, one setup, one payoff, clear on first read.
